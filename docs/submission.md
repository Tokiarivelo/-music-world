## 2. Devpost description (draft, category Frankenstein)

**Project name:** Music World

**Tagline:** Turn any song into a living 3D world you can explore in the browser or in VR on Meta Quest.

**Inspiration.** Music visualizers react to loudness; they don't understand music. We wanted a world that is built
from the actual notes, chords and structure of a song — and that you can step into.

**What it does.** Upload a song (MP3, WAV or FLAC, up to 3 minutes). Music World analyses it, then plays it as a 3D
world: notes slide along a glowing musical staff, fall onto a cracked terrain plate and grow into a neon city.
An AI World Director (Meta Muse or Claude on Amazon Bedrock) reads the harmony, energy and lyrics and designs a new
world template; you can compare providers side by side. Templates can be published to a community store (our
Kiroween launch template: *Kiroween Pumpkin Night*). On a Meta Quest, the world becomes a tabletop diorama with
controller, hand-pinch and spatial-panel controls.

**Why Frankenstein.** It stitches together parts that don't usually live together: Python DSP and ML (Demucs, Basic
Pitch, librosa), large language models as designers, a deterministic procedural world engine, WebXR through Meta's
Immersive Web SDK, and a community template store — into one app that still feels like a single creature.

**How we built it.** Next.js + IWSDK (Three.js, WebXR) for the web and XR; FastAPI with an arq worker, PostgreSQL and
Redis for the backend; Docker Compose behind Caddy on OVHcloud. Contracts flow from pydantic to JSON Schema to zod.
Two rules shaped everything: algorithms detect notes, LLMs only interpret (LLM output and templates are validated data,
never code); and the world is a pure function of the audio clock, so seeking anywhere shows exactly the right world.

**How we used Kiro.** Seven specs (EARS requirements, design, tasks) drove the work one task per commit; a single
steering source (`.kiro/steering/rules.md`) with file-match rules per area; 11 skills, 4 custom agents and 9 hooks;
a fixed-format handoff file so any agent could resume. Property-based tests (fast-check, Hypothesis) checked by
hand-made mutants found three real data-loss bugs and several vacuous tests. Full write-up: `KIRO_USAGE.md`.

**Challenges.** CPU-only stem separation (about 6.5 minutes for a 3-minute song), Basic Pitch's TensorFlow pin on
Python 3.12 (solved with its bundled ONNX model), and keeping the default look faithful to our reference image within
a Quest frame budget.

**What's next.** Lyrics transcription with Muse Voice, custom shape recipes from the AI director, a template editor.
